
# Smart Campus Resource and Energy Management System

## About the Project

The Smart Campus Resource and Energy Management System is a Java-based application designed to monitor campus energy consumption, control campus resources, calculate electricity costs, and report renewable energy savings.

## Features

- Monitor energy consumption of campus resources.
- Switch resources ON and OFF.
- Calculate electricity costs using energy consumption and tariff rates.
- Report solar energy generation.
- Calculate savings from renewable energy.
- Demonstrate interfaces, default methods, and runtime polymorphism.

## Campus Resources

1. Smart Classroom
2. Computer Laboratory
3. EV Charging Station
4. Solar Power Unit

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Interfaces
- Default Methods
- Runtime Polymorphism

## How to Run

1. Install a compatible Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in IntelliJ IDEA.
4. Open `src/Main.java`.
5. Run the `main()` method.

## Learning Outcomes

This project demonstrates Java interfaces, implementation of multiple interfaces, default-method conflict resolution, encapsulation, and runtime polymorphism.
